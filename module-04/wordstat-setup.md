# Wordstat: подключение точного спроса (ступень 4 методички)

Единственная платная ступень конвейера: реальные цифры поиска Яндекса вместо оценок «на глаз». Стоимость: 20 ₽ за 1000 запросов, на одну статью уходит 1–3 запроса. До подключения скилл статей работает в режиме best-effort (честно помечает оценки как «без API») — можно спокойно отложить эту ступень и вернуться позже.

## Маршрут (30–60 минут)

1. **Yandex Cloud AI Studio** — зайди на https://aistudio.yandex.cloud, создай или выбери облако и каталог (folder). Запиши **ID каталога** — это будущий `YANDEX_FOLDER_ID`. Внимание: нужен ID именно каталога, не облака.
2. **Платёжный аккаунт** — подключи billing account с картой. Без него не проходят даже пробные запросы.
3. **Сервисный аккаунт** — создай в каталоге service account и назначь ему роль **`search-api.webSearch.user`**.
4. **API-ключ** — создай для сервисного аккаунта **Api-Key** (именно Api-Key, не OAuth-токен и не IAM-токен).
5. **Конфиг скилла** — в папке `~/.claude/skills/yandex-wordstat/`:
   ```bash
   cp config/.env.example config/.env
   ```
   Впиши в `config/.env` свой ключ и folder ID.
6. **Проверка:**
   ```bash
   bash scripts/quota.sh
   ```
   Должно ответить «Wordstat API: OK».

Полная инструкция с разбором частых ошибок (401/403, INVALID_ARGUMENT) — в `yandex-wordstat/config/README.md`.

## Грабли, о которых лучше знать заранее

- **Лимиты:** 10 запросов в секунду, 100 в час. Для статей — за глаза.
- **Операторы Wordstat не работают.** API принимает только простой текст фразы (до 400 символов): `!слово`, кавычки, минус-слова и `(a|b)` не интерпретируются.
- **Старые инструкции из интернета не работают.** Классический Wordstat API (`api.wordstat.yandex.net`, OAuth) закрыт — гайды до 2026 года описывают мёртвый путь. Ставь только по этой инструкции.
- **Ключи — только в `config/.env`.** Файл не коммитится в git (`.gitignore` уже настроен). Никогда не вставляй ключ в SKILL.md или промпты.
