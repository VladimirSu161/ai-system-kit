---

3 визуальных сабмода для обложек статьи. Все сохраняют базовую DNA обложек (фотореализм, без роботов/неона, взрослые 40-50, без stock-улыбки), но варьируют **свет, палитру, сцену** и общее настроение. Для одной статьи скилл выбирает **один пак** и применяет ко всем 5 промптам, чтобы внутри выпуска обложки читались как комплект.

## Зачем 3 пака

На странице канала видны десятки обложек разом. Если все 100 статей в одном паке — устаёт глаз, ощущение «опять то же». Если каждая обложка в своём паке — теряется ощущение единого автора. Три пака внутри общего DNA решают оба: в ленте Дзена обложки выглядят свежо, на странице канала — как линейка одного автора в трёх настроениях.

## Доступные паки

|---|---|---|
| `warm-apartment` | `warm-apartment.md` | Объяснялки, гайды для новичка, базовые инструменты, smart home, бытовые AI-кейсы |

| `cinematic-evening` | `cinematic-evening.md` | Тренды, прогнозы, личные кейсы автора, карьера/доход, итоги, opinion-форматы |

## Логика автоматического выбора

В Phase 6 скилл смотрит на тип статьи (определяется в Phase 2 заголовка и по содержанию каркаса) и выбирает пак по таблице выше. Если статья смешанная — приоритет:

1. **Если есть личный кейс или прогноз** → `cinematic-evening`
2. **Если есть сравнение/таблица/нумерованный список как главный смысл** → `editorial-overhead`
3. **Иначе по умолчанию** → `warm-apartment`

Пользователь может явно переопределить пак при запуске («сделай обложки в evening», «возьми editorial»). Если переопределение есть — оно главнее автоматики.

## Что одинаково во всех паках (DNA)

Эти правила НЕ меняются между паками:

- Фотореализм / documentary feel, никаких 3D-рендеров и stock-иллюстраций
- Один главный объект 50-70% кадра, минимум воздуха 30%
- Один акцентный цвет на смысл
- Без текста, водяных знаков, логотипов
- Если человек в кадре — взрослый 40-50, естественная умеренная эмоция (4-6/10), без stock-улыбки, без стереотипа «беспомощного пенсионера»
- Без cyberpunk, неона, роботов, голограмм, server rooms

## Что меняется между паками

- **Свет:** дневной боковой (warm) / ровный сверху (editorial) / тёплый одиночный вечерний (cinematic)
- **Палитра:** бежевый+оливковый / бежевый+приглушённый teal/sage / графит+амбра+бронза
- **Контекст:** обычная квартира/кухня/кафе (warm) / стол сверху flat-lay (editorial) / вечерняя комната, лампа, поздний час (cinematic)
- **Mood words:** calm/everyday / editorial/considered/magazine / cinematic/quiet/contemplative
- **Анти-AI хвост:** общая часть DNA + специфичные палитра+свет из пака

## Интеграция в Phase 6

В Phase 6 (`SKILL.md` родителя):

1. Определи тип статьи → выбери пак (или возьми явно переданный пользователем).
2. Прочти соответствующий файл `references/cover-styles/{pack}.md`.
3. Подставь в шаблон промпта из `cover-formulas.md` строки света/палитры/контекста из пака.
4. Используй анти-AI хвост из пака (не из cover-formulas.md — пак содержит финальную версию хвоста).
5. В блоке вывода в .md файле статьи **в самом начале блока обложек** укажи название пака: `**Стиль:** warm-apartment` (чтобы при перегенерации знать, в каком паке были сделаны).
