# Правила из правок автора

Выучено из сравнения опубликованных статей с исходниками (режим обучения в SKILL.md). Эти правила **приоритетнее** общих правил письма и голоса — это реальная редактура автора перед публикацией. Максимум 25 правил; `(×N)` = сколько раз правка повторялась, чем больше — тем надёжнее правило. Пока канал один, правила пишутся без пометок. Если каналов станет несколько — помечай правило slug'ом канала (например `[my-channel]`); правило без пометки действует для всех.
