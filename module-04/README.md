# Модуль 4 — Конвейер статей

Материалы модуля серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)): полный конвейер статей для Дзена и блога — база знаний классиков письма, проверка поискового спроса, обложки и инфографика.

## Как установить

Скопируй эту строку и отправь своему Claude Code:

> Разверни у меня конвейер статей по инструкции: https://raw.githubusercontent.com/VladimirSu161/ai-system-kit/main/module-04/SETUP.md

Дальше агент всё сделает сам: скачает файлы, разложит скиллы и **проведёт тебя через настройку под твой канал** — задаст вопросы про твою нишу, аудиторию, голос и ссылки, соберёт из ответов профиль и проверит конвейер на реальной теме. Это разговор минут на 15–20.

Почему без разговора никак: файлы здесь обезличены. Голос, темы, аудитория и ссылки внутри пустые — их нельзя скачать, можно только собрать из твоих ответов. Иначе получится статья «ни для кого».

## Что в папке

| Что | Для чего | Ступень методички |
|---|---|---|
| `SETUP.md` | Сценарий разворачивания и персонализации — читает агент | старт |
| `articles-v2/` | Главный скилл: статья от темы до готового файла за 8 фаз | 1 |

| `yandex-wordstat/` | Скилл проверки поискового спроса (Yandex Cloud API, платный, опциональный) | 4 |
| `METHODICHKA.md` | Как конвейер устроен, откуда взялся и как повторить | читать первой |
| `wordstat-setup.md` | Пошаговый сетап Yandex Cloud для Wordstat | 4 |
| `distill-prompt.md` | Промпт для сборки СВОЕЙ базы классиков (другая ниша или язык) | 2, опционально |

## Порядок освоения (для человека)

Читай `METHODICHKA.md`: часть 4 — ступени сборки (после каждой у тебя уже рабочий скилл), части 1–3 — как машина устроена и откуда взялась. Не проходи все ступени за один вечер, так задумано.

Главная ступень — не установка, а **режим обучения**: опубликовал статью со своими правками, вернулся и сказал агенту «опубликовал, вот финал». Скилл превращает твою редактуру в правила, и каждая следующая статья требует меньше правок. Без этого шага конвейер остаётся чужим.
