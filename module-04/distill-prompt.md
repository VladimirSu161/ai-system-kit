# Промпт дистилляции: свой корпус классиков → рабочие референсы (ступень 2 методички)

Этот промпт нужен, только если ты хочешь собрать СВОЮ базу знаний (другая ниша, другой язык, другие авторы). Готовые 4 референса из этого модуля покрывают статьи на русском — для старта их достаточно.

## Шаг 1. Собери корпус

Попроси своего агента провести ресёрч источников по своей нише (пример формулировки):

```
Проведи глубокий ресёрч первоисточников о [письме / твоя тема] по углам:
[копирайтинг, сторителлинг, редактура, твой язык/ниша].
Для каждого источника: ссылка, оценка ценности (ядро / выжимка / контекст)
и главное — поле «что именно брать для скилла»: конкретные правила и методы,
а не пересказ. Итог — каталог в один markdown-файл.
Затем скачай тексты источников из каталога локально в папку sources/
(полные тексты — только для личной рабочей базы, не для публикации).
```

## Шаг 2. Дистиллируй

Скопируй целиком, подставь своё:

```
Дистиллируй корпус источников из папки [путь к sources/] в рабочие
референс-файлы для скилла [имя скилла]: [список файлов, например
hooks.md — заголовки и лиды; structure.md — структура и нарратив;
editing.md — редактура; simplicity.md — язык].

Правила дистилляции (жёсткие):

1. В референс попадают ТОЛЬКО проверяемые правила и процедуры.
   «Пиши интересно» — не правило. «Если два абзаца подряд соединены
   только "и/также" — перепиши переход через "но" или "поэтому"» —
   правило: его можно проверить глазами или grep-ом.
2. У каждого правила — автор в скобках, чтобы при сомнении вернуться
   к источнику.
3. Правило, дублирующее уже существующее в скилле или в другом
   референсе, не добавляется — помечай «это одно правило, не два».
4. К каждому своду — предохранитель: классики писали эвристики,
   не законы. Явно напиши, когда правила можно нарушать, и добавь
   анти-паттерны механического применения (например: инфостиль без
   предохранителя пересушивает текст до робота).
5. Целевой объём каждого файла — 40–80 строк. Если получается больше,
   ты пересказываешь книгу, а не дистиллируешь правила.
6. Полные тексты источников в референсы не копировать — только правила
   и короткие цитаты.

После дистилляции скажи, какой файл на какой фазе скилла подключается:
что читается при выборе заголовка, что подставляется в промпт писателя,
что используется при финальной редактуре.
```

## Шаг 3. Подключи

В скилле статей референсы подключаются в трёх местах (см. SKILL.md): заголовочный файл читается на Фазе 2, структура и язык подставляются в промпт писателя на Фазе 3, редактура прогоняется чеклистом на Фазе 4. Свои файлы подключай по той же схеме: замени содержимое соответствующих файлов в `references/` или добавь свои и поправь пути в SKILL.md и article-writer-prompt.md.
