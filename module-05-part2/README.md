# Модуль 5, часть 2 — Видео-цех на Remotion (reelcraft)

Материалы модуля 5 (часть вторая) серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)).

Второй видео-цех: голос → вертикальный ролик 1080×1920 на **Remotion**.
Пословные караоке-субтитры, живые скриншоты с наездом камеры, монтаж по
каталогу из 152 приёмов, звуковые эффекты, музыка с дакингом под речь.
Всё локально.

**Чем отличается от части 1 (HyperFrames).** Там ролик собирался как
HTML-страница с анимацией на JS. Здесь сцены — это React-компоненты
Remotion: покадровый детерминированный рендер, готовые компоненты камеры,
переходов и субтитров, автоматические проверки вёрстки до рендера. Это
самостоятельный цех, а не надстройка: части не зависят друг от друга,
можно ставить только эту.

## Состав модуля

| Что | Где | Зачем |
|---|---|---|
| Каркас проекта | `reelcraft-kit/` | копируется как рабочий проект видео-цеха |
| Мастер настройки | `reelcraft-kit/SETUP.md` | пошаговая установка от зависимостей до первого ролика (ведёт агент) |
| Правила конвейера | `reelcraft-kit/CLAUDE.md` | 27 правил темпа, композиции и звука — по ним собирается каждый ролик |
| Скилл конвейера | `reelcraft-kit/SKILL.md` | ставится в `~/.claude/skills/reelcraft/` — команда «/reelcraft» делает ролики |
| Лицензии | `reelcraft-kit/LICENSES.md` | происхождение каждого материала и что можно с ним делать |

В каркасе: движок Remotion с 17 общими компонентами (камера по скриншотам,
караоке, персонаж, музыка с дакингом, CTA-карточка, макеты окон и схем),
две темы (светлая с персонажем и тёмная), разбор 152 приёмов монтажа,
скрипты обработки звука и распознавания речи, линт сцен и авто-QA по
контактному листу, 2000 иконок Lucide и 67 логотипов брендов, шрифты.

## Инструкция для агента

Ты — Claude Code ученика. Установи материалы модуля:

1. Скачай репозиторий во временную папку:
   ```bash
   git clone --depth 1 https://github.com/VladimirSu161/ai-system-kit /tmp/ai-system-kit
   ```
   (без git: скачай ZIP `https://github.com/VladimirSu161/ai-system-kit/archive/refs/heads/main.zip` и распакуй)
2. Спроси у пользователя, куда положить проект (по умолчанию `~/reelcraft`),
   и скопируй туда содержимое `module-05-part2/reelcraft-kit/`. Если по этому
   пути уже что-то есть — покажи пользователю и спроси, ничего не перезаписывай
   молча.
3. Дальше действуй по `SETUP.md` внутри скопированного проекта — он ведёт от
   проверки системы до первого ролика, шаг за шагом, с проверкой после каждого.
4. Учти заранее и предупреди человека: понадобится скачать модель
   распознавания речи (1.5 ГБ) и зависимости движка (~500 МБ), а на шаге 6
   он должен будет назвать хендл своего канала, слоган и дать скрин шапки
   канала.

## Что не входит в комплект и почему

Часть материалов нельзя перевыкладывать по лицензии — их устанавливает сам
агент из первоисточников на шагах 3 и 5:

- **каталог 152 приёмов** — отдельный открытый проект
  [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) (Apache-2.0),
  клонируется рядом с проектом;
- **звуковые эффекты** — берутся из этого же клона скриптом;
- **музыка** — бесплатные треки Mixkit, качаются с mixkit.co;
- **Lottie-анимации** — у распространённых наборов лицензия разрешает
  использовать анимации в роликах, но запрещает перевыкладывать файлы;
- **персонаж светлой темы** — в комплекте только силуэты-заглушки, свои
  генерируются на шаге 7.

Происхождение и лицензия каждого материала, который в комплект входит, —
в `reelcraft-kit/LICENSES.md`, полные тексты лицензий — в
`reelcraft-kit/licenses/`, атрибуция заимствованного кода — в
`reelcraft-kit/NOTICE`.
