# Библиотека приёмов video-shotcraft — категории ui-entrance + rhythm

Инвентаризация 38 карточек (27 ui-entrance + 11 rhythm) для конвейера вертикальных говорящих роликов 1080×1920, 40–90 сек, голос диктует тайминги, полоса караоке-субтитров y 880–1030, в одной теме персонаж снизу y 960–1920 слева. Приёмы живут в info-zone y 110–870.

Все карточки — на китайском в оригинале, ниже смысл переведён на русский. Пути даны от папки клона video-shotcraft (по умолчанию `../video-shotcraft/skill/` рядом с проектом — см. SETUP.md).

---

- Звук: сильная зависимость — полоски обязаны реагировать на реальный звуковой спектр (visualizeAudio), без синхронной музыки приём читается как баг интерфейса
- Грабли: один раз за ролик и только на одном элементе-носителе (не дублировать на разделителях карточек); финальная линия должна совпасть с исходной попиксельно, иначе "возврат" не считывается
- Demo: video-shotcraft/skill/demos/rhythm/spectrum-morph-ui/SpectrumMorphUi.tsx

### speed-ramp-freeze · rhythm
- Суть: два приёма ремапа времени — вариант "разгон-фриз-разгон" (резкое замедление до почти-стопа на важной детали) и вариант "стоп-кадр с аннотацией" (полная остановка + маркерная обводка важного места + стрелка, затем разморозка)
- Триггеры: акцент «смотри сюда» (задержка взгляда на важном), демонстрация с аннотацией / «как работает X» (обучающий стоп-кадр)
- Энергия: средне-высокая · Длительность: ~4–5с каждый
- Вертикаль: ок — техника ремапа времени не зависит от пропорций кадра, важно лишь центрировать выделяемый объект
- Звук: звук резки должен идти по выходным кадрам, не по исходным; для стоп-кадра — звук маркера ("шшш")
- Грабли: приём стоп-кадра с аннотацией — не чаще 2 раз за 30-секундный ролик; при разгоне обязательна связка "быстро=размыто / медленно=чётко" — без этого контраста скоростей приём не читается
- Demo: video-shotcraft/skill/demos/rhythm/speed-ramp-freeze/FreezeAnnotateReal.tsx + SpeedRampReal.tsx

### trailer-grammar-moves · rhythm
- Суть: три структурных момента трейлера — A trailer-bumper (три ярких кадра быстрой резки перед стартом + чёрная тишина + заголовок), B card-footage-cadence (UI-кадры чередуются с чёрными текстовыми карточками в такт), C smash-cut (нарастающий хаос движения обрывается ОДНИМ кадром в полную статичную тишину)
- Триггеры: A хук (открывающий крюк), B переход между мыслями (диалог "картинка-текст", тройная подача преимуществ), C результат-финал (кульминация в тишину)
- Энергия: A/C высокая, B средняя · Длительность: ~4.5–5с каждая
- Вертикаль: с адаптацией — техника монтажной грамматики переносима, но композиции кадров (широкие планы, крупные надписи) нужно проверять в узком кадре
- Звук: сильная зависимость по всем трём — A звуковой удар на каждом из 3 резов + полная тишина на чёрном кадре, C музыка обрывается тем же кадром, что и картинка
- Грабли: C — вход в финальный рез должен идти на УСКОРЕНИИ, а не на замедлении (это ключевое правило); A — чёрный кадр обязан быть абсолютно пустым, ничего в нём быть не должно
- Demo: video-shotcraft/skill/demos/rhythm/trailer-grammar-moves/CardFootageCadence.tsx + SmashCut.tsx + TrailerBumper.tsx

## Звёзды пакета

Топ-5 приёмов из этих двух категорий именно под вертикальный говорящий ролик (голосовой темп, узкая колонка info-zone, минимум адаптации):

1. **list-reveal** — единственный приём в подборке, который вертикали не требует адаптации вообще: список пунктов сверху вниз — это и есть родная форма вертикального кадра. Низкая энергия удобно ложится под ровный голос диктора.
2. **doc-park-left-pill-deal** — редкий приём, у которого тайминг уже спроектирован под длину произносимой фразы (0.22 от общей длительности = "успеть сказать предложение"), идеально для формата "голос диктует темп". Требует адаптации (источник вверх, а не влево), но логика "источник остаётся в кадре, выводы копятся по одному" — то, что нужно.
3. **draw-svg-trace** — самый дешёвый и универсальный акцент «смотри сюда» на любую карточку в info-zone: элементный уровень, не завязан на пропорции, не требует адаптации, подходит под любую точку, где диктор говорит "смотри вот сюда".
4. **beat-step-list-theme-cycle** — плотная перечислительная вставка ("качество за качеством") нативно вертикальна (капсула по центру, слова прокручиваются под неё) и по структуре легко перекладывается на слова диктора вместо музыкального такта.
5. **morph-from-primitive** — компактный, самодостаточный "рождается на месте" приём для открытия смыслового блока: не требует горизонтального пространства, не конфликтует с персонажем внизу кадра, хорошо садится на паузу в речи перед новой темой.
