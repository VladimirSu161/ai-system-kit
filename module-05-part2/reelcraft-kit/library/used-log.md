# Журнал использованного (анти-повтор)

Заполняется после каждого сданного ролика — шаг 9 конвейера. Нужен, чтобы
соседние ролики не повторяли хук, приёмы и музыку: перед сторибордом агент
читает две последние строки и не берёт оттуда ни хук, ни трек.
