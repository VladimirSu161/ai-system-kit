# Готовые компоненты shotcraft (assets/lib) — НЕ переписывать, копировать

Источник: `../video-shotcraft/skill/assets/lib/` (локальный клон, никуда
не денется). Правило shotcraft: компонент КОПИРУЕТСЯ в проект ролика в момент,
когда сториборд выбрал приём, стоящий на нём, и дальше правится свободно
(не импортировать из клона). Писать свой аналог с нуля = выбросить их
отладку — запрещено, сначала смотреть сюда.

ОБЯЗАТЕЛЬНО на сториборде: если сцена попадает в один из случаев ниже —
в паспорт задания Sonnet'у вписывается путь к компоненту.

| Компонент | Что делает | Когда брать |
|---|---|---|
| `PageCam.tsx` | 2.5D-камера по странице: полноэкранная текстура скриншота + наезды/панорамы ключевыми кадрами + оверлеи в координатах страницы; внутри — трюк CSS zoom для чёткости текста при наезде (их правило Q2) | ЛЮБОЙ пролёт/наезд по скриншоту сервиса или репо — фундамент всех «живых страниц» |
| `DigitRoll.tsx` | одометр: колонки цифр прокручиваются до значения (моноширинный шрифт) | большая цифра, счётчик, цена |
| `VerticalTicker.tsx` | 3D-стена бесконечной вертикальной прокрутки (items = любые ReactNode; маска, перспектива, скорость — пропсы) | поток карточек/строк/логотипов «их много» |
| `FlashCut.tsx` | тёпло-белый блум поверх жёсткой склейки | акцентная склейка сцен (только тема без персонажа; НЕ строб — одиночная вспышка склейки) |
| `Caption.tsx` | инфо-полоска низа кадра (моно, янтарный квадратик) | подпись-примечание; ⚠ дефолт 22px ниже нашего порога читаемости — поднимать размер (правило 13) |
| `FlatPanel.tsx` | панель в настоящем 3D (three) с контактной тенью | только если сториборд требует настоящий 3D-наклон; тянет three + @react-three/fiber + @remotion/three — без нужды не брать |
| `helpers/` (motion, rand, shake, camera) | изинги/качание/тряска/камера | уже портированы в `engine/src/lib/helpers.ts`; сверяться при расхождениях; `camera.tsx` (3D) — только вместе с FlatPanel |

Плюс: у отдельных карточек demo лежит в `template/src/aifl/` (путь указан в
записи карточки) — это тоже готовый код, копировать оттуда же.
