# Sticker Light — правила постановки (дефолтная тема)

Тема: `engine/src/themes/light.ts`. Персонаж `public/shared/character/`
(10 поз; `pose-five` списана, брать `pose-wave`), стикеры `stickers/` (6 шт.).

## Персонаж

- Стоит в кадре с f0 (кадр 0 = обложка, низ не пустой).
- Живёт в ролике почти всегда; уходит только под полным покрытием
  полноэкранного перехода и в следующей сцене **выезжает снизу с новой
  эмоцией**, подходящей блоку. Переход = момент смены эмоции.
- Пустой низ кадра недопустим ни в одной сцене.
- Персонаж z=40, переходы z=55, караоке z=60. `Character` задаёт явный zIndex.

## Зоны

- Персонаж в кадре → контент в info-zone **110–870**.
- Персонаж физически за кадром (короткое окно перехода) → весь кадр, центр 960.
- Караоке-полоса **880–1030** неприкосновенна; персонаж стоит ниже, в charZone.
- CTA-карточка 920 ширины по центру, занимает info-zone почти целиком;
  персонаж под ней в charZone, карточку не задевает.

## Стикеры

Только если сториборд явно их запросил и стикер в тему. По умолчанию — нет
(банк из 6 штук регулярно мажет мимо смысла). Lottie — замена стикеров там,
где иконка герой момента.

## Переходы и камера

- Полнокадровые переходы и живая камера разрешены на сценах без персонажа
  и на сценах с персонажем, если не трогают его. Исключение: bottom-push
  может вытолкнуть персонажа вместе со старой сценой, если так поставлено.
- Переходные элементы — акцентные заливки (крем/жёлтый от кнопки CTA):
  светлое на светлом читается как кроссфейд.
- Фон не мигает (правило темпа 7).

## Караоке

56px, полоса 880–1030, OFF там, где крупная типографика дублирует речь.
