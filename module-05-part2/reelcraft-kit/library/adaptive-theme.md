# Самоопределяемая тема

Вторая тема ролика — НЕ фиксированная. Она выводится из транскрипта: о каком
продукте/бренде ролик — такой и визуальный язык. Это порт этапа 1 методологии
shotcraft («визуальный язык растёт из продукта, а не натягивается сверху»).
«GitHub noir» из экспериментов 103 — не «наша тёмная тема», а пример того,
что эта методика выдала для ролика про GitHub. `engine/src/themes/noir.ts`
остаётся референсом-каркасом и фолбэком.

Светлая тема (Sticker Light) под это правило НЕ попадает — она ЗАФИКСИРОВАНА
(узнаваемость канала), меняется только решением автора.

## Порядок на сториборде (мини-этап «визуальное направление»)

1. **Герой ролика.** Из транскрипта: один главный продукт/бренд/среда
   (GitHub, n8n, Telegram, терминал, Excel…). Несколько равноправных или
   тема абстрактная («5 привычек») → фолбэк noir.ts, отметить в сториборде.
2. **Палитра из бренда.** Источники по порядку: манифест иконок
   (`engine/public/shared/icons/manifest.json` — там bg брендов) → реальный
   скриншот продукта из этого же ролика (пипетка по факту) → сайт бренда.
   Собрать по контракту Theme: bg / ink / muted / card / акценты. Фон тёмный
   или светлый — как у продукта (у GitHub тёмный, у Notion светлый).
3. **Характер анимации по двум осям** (таблица пресетов — pipeline.md этап 1
   исходника): энергия (спокойный↔энергичный) и тональность
   (серьёзный↔игривый) → пресет: длительность входа, изинг, овершут.
   Дев-инструменты → «профи-доверие» (~21f, bezier(0,0,.2,1), без отскока);
   потребительские сервисы → «живость» (~27f, лёгкий отскок 1.08).
   Правило-исключение shotcraft: приземление с физической метафорой обязано
   отскочить, даже в строгом пресете.
4. **Зоны кадра НЕ трогать** — contentTop/Bottom, capTop/Bottom берутся из
   noir.ts как есть (проверенные под вертикаль и караоке). Меняется кожа,
   не скелет.
5. **Мини-спек в сториборд**: 5–8 строк — герой, палитра (hex), шрифты
   (дефолт Inter+JetBrains Mono, менять только если у бренда «лицо» — моно,
   рукописный…), пресет анимации, что взято из noir без изменений.
6. **Вёрстка**: Sonnet создаёт `engine/src/videos/video-NN/theme.ts` по
   контракту `themes/types.ts` из мини-спека. Разовая тема живёт у ролика;
   в `src/themes/` попадают только многоразовые (решением автора).

## Грабли

- Кожа ≠ приёмы: карточки каталога темонезависимы, менять у приёма можно
  только цвета/шрифты/материалы, не тайминги и не грамматику движения.
- Один бренд = один визуальный голос: нельзя полролика «под GitHub», потом
  «под Notion» — герой один, остальные бренды живут иконками-сквирклами.
- Караоке-контраст обязателен в любой палитре: слова читаются на фоне
  (проверка — правило 13, стилл 360px).
- Тема с персонажем всегда light; адаптивная тема — всегда БЕЗ персонажа
  (полнокадровые переходы разрешены).
