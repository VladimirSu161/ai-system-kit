# Reelcraft — конвейер вертикальных роликов на Remotion

Запись голоса на входе → готовый вертикальный ролик 1080×1920 на выходе:
пословные караоке-субтитры, живые скриншоты с наездом камеры, монтаж по
каталогу из 152 приёмов, звуковые эффекты, музыка с дакингом под речь,
финальная CTA-карточка канала.

Ролик собирает не человек, а агент (Claude Code) — по правилам, которые
лежат прямо в репозитории. Человек записывает голос и принимает результат.

## Установка

Отдай своему агенту эту команду:

```
Установи конвейер по инструкции SETUP.md в этом репозитории.
```

Агент проведёт установку по шагам: проверит систему, поставит распознавание
речи, склонирует каталог приёмов, соберёт движок, спросит данные твоего
канала и сделает контрольный рендер. Занимает 30–60 минут, в основном —
скачивания.

Нужно заранее: macOS или Linux, интернет, около 4 ГБ места на диске.

## Что внутри

| Папка | Что это |
|---|---|
| `engine/` | Проект Remotion: общие компоненты (`src/lib/`), темы, шрифты, банки ассетов, демо-композиции |
| `library/` | Знания конвейера: маршрутизатор 152 приёмов, разбор каждого приёма, дуга энергии, спеки тем |
| `scripts/` | Обработка звука, распознавание речи, линт сцен, авто-QA, докачка иконок |
| `footage/` | Твой банк живого видео: скринкасты, съёмка, пруфы |
| `CLAUDE.md` | Нормы конвейера: темп, композиция, звук, QA — 27 правил, по которым собирается каждый ролик |
| `SKILL.md` | Порядок сборки ролика для агента (ставится в `~/.claude/skills/`) |
| `SETUP.md` | Инструкция развёртывания — её читает агент |

## Как это работает

```
запись голоса → prep.sh (−14 LUFS, ×1.2)
              → queue-add.sh (whisper: пословный транскрипт)
              → сториборд (агент: биты речи + приёмы из каталога)
              → вёрстка сцен (Remotion/React)
              → линт + авто-QA по контактному листу
              → рендер + мастеринг звука → MP4
```

Правила намеренно жёсткие: минимальная жизнь элемента, одна точка внимания
в кадре, обязательный живой экран, заполненная вертикаль, неприкосновенная
полоса субтитров. Они и делают ролик смотрибельным без ручного монтажа.

## Лицензии

Код и правила конвейера — свободно для личного и коммерческого использования.
Сторонние части (Remotion, каталог приёмов, иконки, шрифты, звук) — со своими
условиями, разбор в [LICENSES.md](LICENSES.md). Коротко: для одного автора и
небольшой команды всё бесплатно, компаниям от 4 человек нужна лицензия
Remotion.
