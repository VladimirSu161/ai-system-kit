# Персонаж светлой темы — сейчас здесь заглушки

Файлы `pose-*.png` в этой папке — серые силуэты-плейсхолдеры. Они нужны
только чтобы движок запускался и было видно, куда встаёт персонаж в кадре.
**Для своего канала их надо заменить** (SETUP.md, шаг 7).

Требования к своим позам:

- 10 файлов PNG с **прозрачным фоном**, имена ровно такие же, как здесь —
  движок ищет позы по этим именам;
- один персонаж в одном стиле, меняются только поза и руки;
- одинаковый рост фигуры на всех позах, иначе персонаж «прыгает» при смене;
- размер около 1056×1140, фигура по центру, без теней на фоне;
- смотреть готовые файлы глазами: лишние руки и обрезанные кисти — частый
  брак генерации, в кадре он бросается в глаза.

Что означает каждая поза: `base` — нейтральная, `welcome` — руки в стороны,
`wave` — приветствие, `present-left`/`present-right` — показывает на объект
сбоку, `think-chin`/`think-cross` — размышление, `shrug` — пожимает плечами,
`stop` — ладонь вперёд, `fists` — собранность, результат.

Подключение — `<Character swapMode="dip" …>` (`src/lib/Character.tsx`).
Режим `fade` не использовать: кроссфейд поз даёт «двух персонажей насквозь».
