# Lottie-банк

Правило: библиотеку целиком не зеркалим, банк растёт по факту потребности.
Только бесплатные анимации, лицензия каждой фиксируется в таблице ниже,
загрузка ТОЛЬКО локально (`staticFile('shared/lottie/<файл>')` + fetch, см.
`src/lib/LottieBadge.tsx`) — по внешнему URL грузить запрещено, иначе рендер
перестаёт быть офлайновым.

Lottie ставится там, где иконка — герой момента (одиночный акцент).
В перечислениях используется статичный SVG-штрих, не анимация.

| key | file | что делает | источник | лицензия |
|---|---|---|---|---|
| smoke | smoke.json | пульсирующий зелёный круг (scale 0.4→1→0.4, 2с loop) — минимальный валидный bodymovin v5 | написан вручную для этого проекта | свободно |

## Как пополнить банк

Банк намеренно пустой: анимации у каждого проекта свои, а чужие файлы не
всегда можно перевыкладывать вместе с репозиторием. Порядок такой:

1. Скачай нужную анимацию себе — например на [lottiefiles.com](https://lottiefiles.com)
   (есть раздел бесплатных) или в наборе, который тебе нравится по стилю.
2. Положи JSON в эту папку.
3. **Обязательно** добавь строку в таблицу выше: файл, что делает, откуда
   взят, под какой лицензией. Без строки анимация для агента не существует —
   он инвентаризует банк по этому файлу (SKILL.md, шаг 4).
4. Проверь условия лицензии до того, как класть файл в git. Частые случаи:
   CC BY требует указания автора; отдельные наборы разрешают использовать
   анимации в своих роликах, но запрещают перевыкладывать сами файлы —
   такие держи локально и добавь их имена в `.gitignore`.

Стиль, который хорошо ложится в обе темы: stroke-иконки на сетке 32px,
цвет штриха перекрашивается при вставке.
