# Правила из правок автора

Этот файл пуст намеренно: его наполняет режим обучения (`SKILL.md`, раздел «Режим обучения на правках»). Когда автор публикует пост из матрицы со своими правками и присылает финал, каждая правка превращается здесь в правило.

Эти правила **приоритетнее** общих правил хуков и `humanizer.md` — это реальная редактура автора. Максимум 25 правил; `(×N)` = сколько раз правка повторялась, чем больше — тем надёжнее правило. Пометки регистра: `[громкий]`, `[курилка]`, `[цинично]`; правка, которая бьёт по нарративному слою, — `[нарратив]`; общее для голоса — без пометки.

Формат правила — одна строка, конкретная и проверяемая при письме. Образец (не правило, удалить после первой настоящей правки):

- `[громкий]` Финал громкого поста — строка «где лежит», без передачи с числом.
