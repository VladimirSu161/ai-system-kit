# Правила из правок автора

Эти правила **приоритетнее** общих правил хуков и `humanizer.md` — это реальная редактура. Максимум 25 правил; `(×N)` = сколько раз правка повторялась, чем больше — тем надёжнее правило. Пометки регистра: `[громкий]`, `[курилка]`, `[цинично]`; правка, которая бьёт по нарративному слою, — `[нарратив]`; общее для голоса — без пометки.

Формат правила — одна строка, конкретная и проверяемая при письме.

Файл наполняет режим обучения (`SKILL.md`, раздел «Режим обучения на правках»): когда автор публикует пост из матрицы со своими правками и присылает финал, каждая правка превращается здесь в правило. Первые пять правил — стартовые: это правки создателя скилла на его собственных опубликованных постах. Правка автора, которая им противоречит, побеждает — тогда стартовое правило удаляется.

## Правила

- Материал представляется мостом ДО первой ссылки на него: «недавно попался гайд по …, сделал из него PDF: там как раз про …». Пост, где второй абзац начинается «в разборе …» без представления, читатель не понимает: «в каком разборе?».
- `[громкий]` (×2) Витрина в громком посте — не перечисление названий блоков материала, а одна общая фраза через известные всем бренды («у Anthropic, OpenAI, Cursor, Google и GitHub есть СВОЁ собственное обучение»). Тёплая деталь про себя, понятная только своим, из громкого поста вырезается.
- `[громкий]` (×2) Финал громкого поста — строка «где лежит», без передачи с числом: «Собрал … в один пост со всеми линками, пост в закрепе в тг-канале (линк в профиле)».
- `[громкий]` (×2) Валидация в громком посте — признание с досадой о пропущенном, а не результат: «только сейчас узнал, что …», «столько времени бы сэкономил». Своя цифра времени — только если автор назвал её в запросе.
- `[громкий]` (×2) В тезисе «сделки» — личная примерка вместо превосходной степени: «подборку, с которой САМ БЫ СТАРТОВАЛ», а не «лучшая подборка». Второй капс в теле допустим, если он на одном слове.
