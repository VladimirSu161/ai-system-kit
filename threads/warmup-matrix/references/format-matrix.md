# Формат матрицы (6 углов × 9 постов = 54; запасных хуков у громких 5, у остальных 3)

Каждый пост — самостоятельный тизер по схеме витрины из `post-scheme.md`: все правила оттуда действуют (ориентир ~500 знаков — не считать и не ужимать под цифру; ссылка в первом комментарии; холодный читатель; короткое тире; без пафоса кроме громких и циничных слотов; реплай-крючок минимум в 2 постах на угол). Отличие одно: в первую треть поста читатель входит через дверь угла (`angles.md`).

## Ячейка угла — 9 постов

| Слот | Регистр | Источник техники |
|---|---|---|
| a | базовый | `hooks.md` — одна техника, по матрице шесть разных |
| b, c, d, e | громкий | `hooks-loud.md` — четыре разные техники, все три жеста (против / за / диалог) закрыты, враг-способ не повторяется |
| f, g | курилка | `hooks-smoke.md` — два разных захода, две разные оси (боль / выгода / возражение) |
| h, i | циничный | `hooks-cynical.md` — два разных несущих приёма из ядра, по файлу несущий не чаще 2 раз, вспомогательный не чаще 4; грубоватая речь без мата, мат только по слову «с матом» |

Почему громких четыре: на практике создателя скилла громкие хуки залетают заметно лучше остальных регистров. Если у автора по данным режима обучения лучше работает другой регистр — пропорцию ячейки можно поменять, сумма остаётся 9.

Техники по всей матрице — по раскладке из Discovery: каждая громкая не чаще 2 раз на 24 слота, каждый заход курилки не чаще 2 раз на 12 слотов, каждый ярлык один раз на файл, каждая цифра не чаще 2 раз.

Разброс внутри угла — **холодные** портреты читателя из `config.md`, раздел «Холодные портреты». Девять постов одного угла берут минимум четыре разных портрета. Тёплые портреты («уже в теме и что-то не получается», «путается в терминах») исключены — под них посты выходят понятными только своим. Каждый пост входит через большую дверь из Discovery п.4, витрина — вопросами читателя, словарь темы запрещён (`clarity.md`, раздел 0).

## Запасные хуки — перезалив одного текста

Под каждым постом — блок «Запасные хуки»: другие первые строки к тому же тексту. **У громких постов (b–e) — 5 запасных, у базы, курилки и циничных — 3.** Тело поста не меняется ни словом.

Зачем: один и тот же текст с разным хуком набирает в разы разное. Наблюдение по чужому аккаунту в Threads: пост с одним телом на трёх хуках — 8 / 22 / 3 лайка; другой пост на двух хуках — 4 и 78 лайков, 5 и 113 репостов. Без запасных непонятно, что не сработало — хук или текст; с ними неудачный пост получает вторую и третью жизнь.

Правила:

- **Хук = только первый абзац** (у громкого — ярлык + тезис с цифрой, 1–3 строки). Запасной встаёт вместо первого абзаца, и второй абзац читается дальше без шва: без «это» и «он», которым не на что сослаться, без повтора цифры, которая уже есть в теле. Не сшивается — переписать запасной, тело не трогать.
- **Запасные — разные приёмы**, ни один не повторяет приём основного хука. **Громкие, 5 запасных:** три с коротким ярлыком — три разных жеста (против / за / диалог, по одному), и два длинных капса — разные по устройству (один — реакция от первого лица «Я …», другой — тезис с цифрой или ценником внутри). Ярлыки запасных не повторяют ярлыки основных постов и в файле не чаще 2 раз; на матрицу нужно ~40 разных ярлыков, поэтому банк запасных ярлыков пишется в Discovery заранее рядом с банком основных. База, курилка, циничные — приёмы своего регистра; регистр поста запасной хук не меняет.
- **Длинный капс — эксперимент, только громкие.** Два из пяти запасных у громкого поста — целиком капсом, 2–3 строки: реакция + тезис + цифра внутри (образец жеста, не для копирования: «Я ДИКО ИЗВИНЯЮСЬ, НО Я 10 ЛЕТ ХОДИЛА К ПСИХОЛОГУ, А МОЖНО БЫЛО С ИИ ЗА 35 МИНУТ»). Правило `hooks-loud.md` «капс — ярлык до 4 слов» здесь намеренно снято. Перезалив покажет, работает ли это у автора.
- **Правда та же:** цифры, ценники и личное в запасных — по тем же правилам, что в основном хуке.

Формат блока — сразу под текстом поста:

```
**Запасные хуки:**
1. [приём] — [первый абзац целиком]
2. [приём] — …
3. [приём] — …
```

Как перезаливать (идёт в раздел «Как пользоваться» файла):

- Пост за двое суток набрал заметно меньше обычного → через 3–5 дней тот же текст с запасным хуком 1, дальше 2 и 3. Залетевший пост тоже можно перезалить через 1–2 недели с другим хуком.
- Между перезаливами одного текста выходят другие ячейки. Один текст — максимум 4 раза у базы, курилки и циничных (основной + 3 запасных) и 6 раз у громких (основной + 5).
- Какой хук залетел — пометить рядом с ним словом «залетел»: так копятся данные, какие приёмы работают.

Из `config.md`, раздел «Куда сохранять». Если формат имени там не задан:

```

```

## Как пользоваться
Одна ячейка в 2–3 дня, углы чередовать (1 → 3 → 6 → 5 → 2 → 4 …), регистры чередовать. Пост не взлетел за двое суток → через 3–5 дней тот же текст с запасным хуком 1, потом 2 и 3; залетевший — можно перезалить через 1–2 недели. Хук, который залетел, пометить словом «залетел». Ссылка на материал — первым комментарием. Посты одного угла подряд не публиковать: каннибализируют друг друга.
