# Humanizer — финальный проход

Прогони **каждый** пост через пять уровней. Нашёл — переписывай молча, без «было/стало». Уровни 1–3 чистят стиль, уровень 4 — живой голос, уровень 5 — устройство текста (по исследованию StoryScope стиль даёт лишь ~3% детекции AI, остальное — структура; уровень 5 нельзя пропускать).

## Уровень 1 — Forensic (всегда)

Явные следы AI, которых в готовом тексте не бывает:

- **Артефакты модели:** `oaicite`, `:contentReference`, `[1]`, `[2]`, любые квадратные сноски.
- **Плейсхолдеры:** `[имя]`, `[вставь сюда]`, `[X]`, `{переменная}`, `___`.
- **Самопризнания:** «как языковая модель», «по состоянию на дату обучения», «у меня нет данных».
- **Outline-замыкания:** «Подводя итог…», «В заключение…», «Заглядывая в будущее…».
- **Множественные тире:** больше двух `—` в одном посте — лишние убрать, связки через запятую/союз/точку.

## Уровень 2 — Strict (по умолчанию)

Слова и обороты, которые выдают AI-текст на русском. Заменяй или выкидывай.

| AI-маркер | Замена / действие |
|---|---|
| представьте / представьте себе | убрать, начать с факта |
| в современном мире / в наше время / в эпоху | убрать целиком |
| ключевой / ключевым является | конкретизировать или убрать |
| важно отметить / стоит подчеркнуть / стоит отметить | убрать, оставить факт |
| невероятный / удивительный / поразительный | заменить цифрой или убрать |
| уникальный | конкретизировать чем именно |
| погружение / погрузиться | разобраться / посмотреть |
| путешествие (метафора) | путь / процесс / убрать |
| раскрыть потенциал / открыть возможности | убрать целиком |
| трансформировать / трансформация | изменить / поменять |
| оптимизировать (без цифры) | ускорить / упростить — с конкретикой |
| экосистема (вне биологии) | набор / связка / убрать |
| синергия | убрать |
| мощный инструмент / мощное решение | убрать «мощный» |
| фундаментально / по сути / в конечном счёте | убрать |
| на самом деле (как филлер) | убрать |
| итак / что ж / давайте разберёмся | убрать, начать с дела |
| не просто X, а Y (negative parallelism) | переписать двумя утверждениями |
| на самом деле всё сводится к / настоящий вопрос в том / в основе всего лежит (псевдоглубокое обобщение) | сказать мысль прямо, без обёртки «откровения» |
| X — это язык Y / архитектура доверия / X становится ловушкой (афористичная формула) | заменить прямой мыслью: что именно и чем это оборачивается |
| «от X до Y» как охват темы (ложный диапазон: X и Y не на одной шкале) | перечислить темы напрямую |

**Симметричные конструкции** — главный AI-маркер. Три однотипных предложения подряд — сломай ритм: одно длинное, одно короткое, одно фрагментом.

**Восклицательные знаки** — максимум один на пост, и только если без него теряется смысл.

## Стоп-лист заезженных финалов и CTA

Эти формулировки уже расползлись по прошлым публикациям и стали конвейерным штампом — **не использовать**, даже с заменой пары слов:

- «Показываю как ↓»
- «Вот как это работает ↓»
- «Весь расклад ↓»
- «Разбираю ↓»
- «Больше про [тема] → [ссылка на канал]»
- «Разбираю такие [штуки/кейсы/инструменты] в тг / в канале»
- «[Тема] разбираю подробнее у себя в тг»

Правильный финал/CTA выводится из содержания конкретного поста: что именно человек получит за ссылкой или в канале — своими словами, каждый раз заново. Совпал со стоп-листом — переформулируй. Со старыми публикациями не сверяйся, их не читают (`SKILL.md`, шаг 1, «Чистый лист»).

**Стоп-лист против ясности не работает.** Финал обязан прямо называть, что за ссылкой (формат + объём + польза — см. «финал-витрина» в `post-scheme.md`); переформулируй слова, но не размывай суть до загадки («такое встретишь ещё у пары из десяти ↓» — брак: обошёл стоп-лист ценой понятности). Внутри одной матрицы похожие финалы-витрины — норма, стоп-лист сравнивает с опубликованным, а не между кандидатами одного файла.

## Уровень 3 — Burstiness (быстрая проверка)

- Длина предложений варьируется? Все по 10-15 слов — одно сделать в 3-5, одно в 20+.
- Есть хотя бы один фрагмент (неполное предложение)? Нет — добавить.
- Фрагментов и фраз-ударов не серия: «Это не сработало. Никакой логики. Ноль.» — три обрубка подряд читаются как наигранная драматизация, такой же AI-маркер, как ровный ритм. Одна короткая фраза для акцента, дальше нормальное предложение.
- Есть конкретика: цифра, имя, деталь? Абстрактно — вытащить конкретику из исходника.

## Уровень 4 — Живой голос (положительная проверка)

Уровни 1-3 говорят, чего быть не должно. Этот — как должно звучать. Текст, прошедший только чистку, получается грамотным и никаким.

**Тест пересказа другу.** Перескажи готовый пост вслух за 30 секунд, будто звонишь приятелю: «слушай, тут такая штука…». Записал, как сказал, — сравни с постом. Если устная версия живее и понятнее — переписывай пост от неё, а не правь черновик по кускам.

**Живость даёт конкретная сцена, а не разговорные вставки.** «Три часа копируешь цены в таблицу, страница за страницей» — живо. «Ну, знаешь, бывает такая ситуация» — имитация живости. Если хочется добавить разговорный оборот — сначала проверь, нельзя ли вместо него добавить деталь.

**Обратная граница (перекачало в живость).** Потолки на один пост (до 500 знаков):

- разговорные обороты («беда в том», «получается», «на пальцах») — 0-1;
- восклицательные знаки — 0;
- риторические вопросы — 0-1;
- короткие фразы-удары (до 4 слов) подряд — не больше одной, серия из двух-трёх — перебор;
- «я» — не в каждом предложении.

Перебор по двум и более пунктам — откати часть правок: пост должен звучать как автор, а не как блогер, изображающий живость.

## Уровень 5 — Нарративный чек (блокирующий)

Источник и полные правила: `narrative-human.md` (файл обязателен, без него проход не считается выполненным). По каждому посту:

1. Финал не проговаривает мораль и не подводит «урок» — заканчивается действием, фактом, ссылкой-витриной или незакрытым вопросом?
2. Оценка названа прямо («зашло», «бесит», «не понял»), телесных метафор эмоции нет?
3. Читатель в кадре — есть прямое обращение к его ситуации или ремарка-в-сторону?
4. У рекомендации есть цена или сомнение автора (не «balanced», а «выбрал и заплатил»)?
5. Для 1–2 постов каждого угла: есть ровно одно отступление не по теме и хотя бы одно имя собственное из внешнего мира?
6. Финал не тише хука (отпечаток Claude — ровный накал)?

Два «нет» — переписать устройство поста, а не слова.

**Предохранитель.** Все правила humanizer — эвристики. Нарушай любое, если следование делает фразу корявой для устной речи.

## Что НЕ трогать

- Намеренные фрагменты («Вот так.», «И всё.»)
- Строчные буквы в начале — если намеренно
- Разговорные сокращения («щас», «такое», «ну»)
- Числа, имена, термины из исходника
- Короткое тире `-` (оставляем; длинное `—` убираем)
