# Модуль 2 — Установка, CLAUDE.md и память

Материалы модуля 2 серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)).

Что внутри:

- **claude-md-writer/** — скилл: помогает создавать и наводить порядок в файлах CLAUDE.md по официальным best practices (размер, структура, вынос правил в отдельные файлы).
- **prompts.md** — 5 готовых промптов к урокам модуля: персональный CLAUDE.md через интервью, правила под свои задачи, настройка settings.json, система памяти и её ревизия.

## Инструкция для агента

Ты — Claude Code ученика. Установи материалы из этой папки:

| Файл | Raw-ссылка | Куда ставить |
|---|---|---|
| claude-md-writer/SKILL.md | https://raw.githubusercontent.com/VladimirSu161/ai-system-kit/main/module-02/claude-md-writer/SKILL.md | ~/.claude/skills/claude-md-writer/SKILL.md |

Шаги:

1. Скачай файл по raw-ссылке: `curl -fsSL <ссылка> -o <куда ставить>` (создай недостающие папки: `mkdir -p ~/.claude/skills/claude-md-writer`).
2. Если файл уже существует — покажи пользователю разницу и спроси, перезаписывать ли.
3. `prompts.md` устанавливать НЕ нужно — это готовые промпты, пользователь копирует их сам по ходу уроков. Не выполняй их при установке.
4. Проверь установку: файл `~/.claude/skills/claude-md-writer/SKILL.md` существует и начинается с YAML-заголовка `name: claude-md-writer`. После перезапуска сессии скилл появится в списке доступных.
5. Расскажи пользователю по-русски: установлен скилл claude-md-writer — теперь при просьбе «создай CLAUDE.md» или «наведи порядок в CLAUDE.md» Claude будет делать это по best practices. Промпты к урокам лежат в prompts.md этой папки — их копируют в чат по одному.
