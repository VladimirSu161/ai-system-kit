# Модуль 2 — Промпты

Готовые промпты к урокам модуля. Копируй нужный целиком и вставляй в Claude Code.

**Для агента:** это тексты запросов для пользователя, их НЕ нужно никуда устанавливать или выполнять при установке материалов.

---

## Промпт 1. Персональный CLAUDE.md через интервью

```
Проведи со мной короткое интервью, чтобы написать мне персональный файл CLAUDE.md —
правила, по которым ты будешь работать со мной в каждой сессии.

Задавай мне по одному вопросу за раз, не все сразу, дожидайся моего ответа на каждый:

1. На каком языке мне всегда отвечать?
2. Какой у меня уровень: разбираюсь в коде/технике или новичок? Нужно ли объяснять
   термины простыми словами?
3. Чем я занимаюсь и для каких задач я буду тебя чаще всего звать?
   (например: тексты, разбор документов, таблицы, идеи, код — подставь своё)
4. Какие действия для тебя опасные или необратимые, перед которыми ты обязан спросить
   моё разрешение? (удаление файлов, отправка чего-либо в интернет, изменение важных
   документов — подставь своё)
5. Есть у меня особенности стиля общения, которые тебе стоит учитывать?
   (например: не люблю длинные списки, хочу чтобы ты спорил, если видишь решение
   лучше, не люблю канцелярит — подставь своё)
6. Где мы будем обычно работать — есть уже структура папок, куда класть результаты?
7. Есть что-то, что тебе категорически нельзя делать без моего явного разрешения?
8. Что ещё важно знать обо мне с первой секунды новой сессии?

После того как я отвечу на все вопросы, напиши на их основе файл CLAUDE.md на русском
языке, простым языком, по разделам (минимум: язык и стиль, кто я, правила безопасности,
порядок в рабочей папке). Сохрани его как мой ГЛОБАЛЬНЫЙ файл правил — ~/.claude/CLAUDE.md,
чтобы он работал из любой папки (если такой файл уже существует — сначала покажи, что
хочешь в нём изменить, и дождись моего «ок»). В конце покажи мне итоговый текст файла.
```

## Промпт 2. Три правила под мои реальные задачи

```
Посмотри мой файл CLAUDE.md целиком и предложи 3 правила, которые стоит добавить
под мои реальные задачи — судя по тому, чем я тебя обычно прошу заниматься за
последние сессии. Не абстрактные советы, а готовые формулировки для файла.
После того как я выберу нужные — добавь их в CLAUDE.md сам.
```

## Промпт 3. Настройка settings.json: секреты, звуки, строка статуса

```
У Claude Code есть файл настроек ~/.claude/settings.json — настрой мне в нём
три вещи (если файла нет — создай; если уже существует — ничего из него не
удаляй, только добавляй):

1. Защита секретов: через permissions.deny запрети себе читать файлы .env
   и .env.*, файлы со словами secret или credential в имени, и папку ~/.ssh.
2. Звуковые сигналы (хуки): когда ты закончил ответ и когда ждёшь моего
   подтверждения — проигрывай два разных коротких системных звука. Команду
   подбери сам под мою систему (у меня [Mac / Windows / Linux — подставь своё]).
3. Строка статуса: внизу терминала показывай текущую модель и заполненность
   контекста.

Перед сохранением покажи мне итоговый файл целиком и объясни каждую строчку
простыми словами. Записывай только после моего «ок». В конце подскажи, как
проверить, что защита секретов работает.
```

## Промпт 4. Система памяти

```
Настрой мне систему памяти:

1. Создай папку memory/, а в ней файл MEMORY.md с заголовком
   «Оглавление памяти» и пояснением: одна строка на факт, формат
   «- [название](файл.md) — суть одной фразой».

2. Допиши в мой CLAUDE.md (в корне рабочей папки, если файла ещё
   нет — сначала создай его) раздел «Память» со следующими
   правилами:

## Память
- При старте сессии прочитай MEMORY.md и profile.md (если он уже есть).
- Когда в разговоре появляется важный факт (моё решение,
  предпочтение, деталь проекта, договорённость) — сохрани его:
  отдельный файл в memory/ + строка в MEMORY.md.
- Если я говорю «запомни: ...» — сохраняй без обсуждений.
- Перед сохранением проверь, нет ли уже файла про это —
  тогда обнови его, а не создавай дубль.
- Факт устарел или оказался неверным — исправь или удали.
- Личное и чувствительное (пароли, финансы, здоровье) —
  не записывай, пока я прямо не попрошу.

Покажи, что получилось, и объясни своими словами, как будешь
этим пользоваться дальше.
```
