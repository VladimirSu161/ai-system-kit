# AI System Kit — раздатка клуба AI BASE

Материалы к серии видео «Личная AI-система»: скиллы, правила, конфиги и промпты для Claude Code. Автор — Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai).

## Как пользоваться

Каждому модулю серии соответствует папка. Внутри — файл `README.md` с инструкцией для AI-агента: что скачать, куда положить, как проверить.

**Самый простой способ установить материалы** — скопировать ссылку на README нужной папки и сказать своему Claude Code:

> Установи материалы по инструкции: <ссылка>

Агент сам скачает файлы и разложит их по местам.
