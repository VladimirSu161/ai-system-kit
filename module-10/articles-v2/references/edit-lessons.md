# Правила из правок автора

Выучено из сравнения опубликованных статей с исходниками (режим обучения в SKILL.md). Эти правила **приоритетнее** общих правил письма и голоса — это реальная редактура автора перед публикацией. Максимум 25 правил; `(×N)` = сколько раз правка повторялась, чем больше — тем надёжнее правило. Если правило касается только одного канала — помечай его slug'ом (например `[ai-base]`); правило без пометки действует для всех каналов.
