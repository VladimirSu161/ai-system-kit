# Модуль 10 — Конвейер статей (скилл articles-v2)

Материалы к ролику 10 серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)): полный конвейер статей для Дзена/блога с базой знаний классиков письма, проверкой спроса и инфографикой.

Что в папке:

| Что | Для чего | Ступень методички |
|---|---|---|
| `articles-v2/` | Главный скилл: статья от темы до готового файла за 8 фаз | 1 |
| `yandex-wordstat/` | Скилл проверки поискового спроса (Yandex Cloud API, платный, опциональный) | 4 |
| `zen-infographic/` | Скилл инфографики HTML→PNG для тела статьи (опциональный) | 5 |
| `METHODICHKA.md` | Методичка: как конвейер устроен, откуда взялся, как повторить | читать первой |
| `wordstat-setup.md` | Пошаговый сетап Yandex Cloud для Wordstat | 4 |
| `distill-prompt.md` | Промпт для сборки СВОЕЙ базы классиков (другая ниша/язык) | 2, опционально |

## Инструкция для агента

Ты — Claude Code ученика. Установи материалы модуля так:

1. **Скачай папку модуля** (файлов много, поэтому клонируем репозиторий во временную папку, а не качаем по одному):
   ```bash
   git clone --depth 1 https://github.com/VladimirSu161/ai-system-kit /tmp/ai-system-kit
   ```
2. **Разложи скиллы** (если какая-то из папок уже существует — покажи пользователю разницу и спроси, перезаписывать ли):
   ```bash
   cp -R /tmp/ai-system-kit/module-10/articles-v2 ~/.claude/skills/articles-v2
   cp -R /tmp/ai-system-kit/module-10/yandex-wordstat ~/.claude/skills/yandex-wordstat
   cp -R /tmp/ai-system-kit/module-10/zen-infographic ~/.claude/skills/zen-infographic
   ```
3. **Методичку и инструкции** положи туда, где пользователь хранит материалы курса (спроси, если не знаешь):
   ```bash
   cp /tmp/ai-system-kit/module-10/METHODICHKA.md /tmp/ai-system-kit/module-10/wordstat-setup.md /tmp/ai-system-kit/module-10/distill-prompt.md <папка материалов>/
   ```
   Потом удали временную папку: `rm -rf /tmp/ai-system-kit`.
4. **Создай профиль канала пользователя** — без него скилл не запустится. Открой `~/.claude/skills/articles-v2/references/channels/_template.md`, задай пользователю по одному вопросу на секцию (название канала и ссылки для CTA; целевая аудитория одной калибровочной строкой; темы: ядро и что НЕ канала; голос: тон + пример абзаца; куда сохранять статьи) и сохрани заполненный профиль как `~/.claude/skills/articles-v2/references/channels/<slug>.md`. Это ступень 1 методички — подробности там.
5. **Wordstat НЕ настраивай сейчас.** Это платная опциональная ступень. Скажи пользователю, что скилл статей уже работает без него (оценка спроса помечается как «без API»), а когда захочет точные цифры — инструкция в `wordstat-setup.md`.
6. **Для инфографики** (опционально, ступень 5): в папке `~/.claude/skills/zen-infographic/` выполни `npm install` (нужен Node.js; поставит Puppeteer для рендера PNG).
7. **Проверка:** попроси пользователя сказать «напиши статью про [тема из его ниши]». Скилл должен пройти фазы (профиль → спрос/факты → заголовок → текст → проверки) и сохранить файл статьи. Если exa MCP не подключён (веб-поиск фактов), подключи: `claude mcp add exa -e EXA_API_KEY=<ключ с dashboard.exa.ai> -- npx -y exa-mcp-server` — ключ бесплатный, спроси его у пользователя.
8. **Расскажи пользователю по-русски**, что установлено: конвейер статей (одна фраза с темой → готовая статья с заголовком, проверенными фактами и структурой), где лежит методичка и что следующий шаг — прочитать в ней часть 4 (ступени) и пройти чек-лист ученика.

## Порядок освоения (для человека)

Читай METHODICHKA.md: часть 4 — ступени сборки (после каждой ступени скилл уже работает), части 1–3 — как машина устроена и откуда взялась. Не проходи все ступени за один вечер — так задумано.
