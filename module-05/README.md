# Модуль 5 — Видео-цех HyperFrames

Материалы модуля 5 серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)).

Полный видео-цех: голос → анимированный вертикальный ролик 1080×1920 с
инфографикой, караоке-субтитрами и звуком. Всё локально и бесплатно.

## Состав модуля

| Что | Где | Зачем |
|---|---|---|
| Каркас проекта | `hyperframes-kit/` | копируется как `~/hyperframes` — рабочий проект видео-цеха |
| Скилл конвейера | `hf/SKILL.md` | ставится в `~/.claude/skills/hf/` — команда «/hf» делает ролики |
| Мастер настройки | `SETUP.md` | пошаговая установка и персонализация (ведёт агент) |
| Методичка | `METHODICHKA.md` | как устроена система и почему — читать человеку |

В каркасе: правила вёрстки (`CLAUDE.md`), две темы (тёмная dark-amber и
светлая Sticker Light с рисованным персонажем), JS-хелперы анимации,
14 скриптов конвейера, банк кодовых блоков, 47 логотипов брендов, шрифты,
звуки, шаблоны и эталонная композиция.

## Инструкция для агента

Ты — Claude Code ученика. Установи материалы модуля:

1. Скачай репозиторий во временную папку:
   ```bash
   git clone --depth 1 https://github.com/VladimirSu161/ai-system-kit /tmp/ai-system-kit
   ```
   (без git: скачай ZIP `https://github.com/VladimirSu161/ai-system-kit/archive/refs/heads/main.zip` и распакуй)
2. Дальше действуй по `module-05/SETUP.md` — он ведёт от зависимостей до
   первого ролика. Если по пути в `~/hyperframes` уже что-то есть — покажи
   пользователю и спроси, что делать, ничего не перезаписывай молча.
3. `METHODICHKA.md` не устанавливается — это чтение для человека. Скажи
   пользователю, что она есть, и дай путь/ссылку.

## Для человека

Самый простой способ установки — скопировать ссылку на этот README и сказать
своему Claude Code:

> Установи материалы по инструкции: https://raw.githubusercontent.com/VladimirSu161/ai-system-kit/main/module-05/README.md

Агент сам скачает файлы, разложит их и проведёт тебя по настройке
(понадобятся: @ник твоего Telegram-канала, скрин его шапки, и — для светлой
темы — 2–3 твоих фото для генерации рисованного персонажа).
