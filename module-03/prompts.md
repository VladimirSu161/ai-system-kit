# Модуль 3 — Промпты

Готовые промпты к урокам модуля. Копируй нужный целиком и вставляй в Claude Code.

**Для агента:** это тексты запросов для пользователя, их НЕ нужно никуда устанавливать или выполнять при установке материалов.

---

## Промпт 1. Развернуть структуру системы по трём слоям

```
Разверни мне структуру системы по трём слоям — конфиг, рабочий хаб, архив.

Шаг 1. Рабочий хаб (эта папка). Проверь, есть ли в ней файл CLAUDE.md.
Если нет — создай его. Если есть — дополни. В файле должна быть таблица:
какая подпапка за что отвечает (создай подпапки под мои реальные задачи,
например: [подставь своё, чем занимаешься: контент, документы, проекты...]).
Плюс правило текстом: "новый проект — новая подпапка, в корень файлы
не класть".

Шаг 2. Архив знаний. Создай рядом с ai-base папку obsidian-vault
(на одном уровне, не внутри ai-base). Внутри неё сделай ровно 5-6 папок,
без лишнего дробления:
- content/ — готовый итоговый контент (посты, статьи, документы)
- profile/ — заметки обо мне: кто я, чем занимаюсь, как работаю
- daily/ — ежедневные заметки и дневник
- rules/ — правила и памятки, включая карту этой структуры
- projects/ — рабочие материалы по темам/проектам
- _inbox/ — всё новое и ещё не разобранное

Шаг 3. Правило именования файлов. Запиши его текстом в
obsidian-vault/rules/наименование.md: "Имя файла = понятное описание,
по которому сразу ясно, что внутри + дата в конце. Например: Пост про
[подставь своё] – 2026-07-10.md. Никаких 'новый файл 2' и 'черновик
финал'."

Шаг 4. Покажи мне итоговое дерево обеих папок и объясни в двух словах,
что где лежит.
```

## Промпт 2. Настроить автоматические бэкапы на GitHub

```
Настрой мне автоматические бэкапы моей системы на GitHub. Я новичок,
объясняй каждый шаг простыми словами, прежде чем его делать.

Шаг 1. Проверь, установлены ли у меня git и gh (это консольная утилита
GitHub). Если нет — установи через brew, если он есть, или скажи мне,
что поставить сначала. [Windows: подскажи установку через winget.]

Шаг 2. Проведи меня через авторизацию: я сам зарегистрируюсь на
github.com, если у меня ещё нет аккаунта, а дальше запусти
`gh auth login` и подскажи, что отвечать на вопросы у меня в терминале.

Шаг 3. Создай ДВА приватных репозитория на моём GitHub-аккаунте:
один под папку ai-base, второй под папку obsidian-vault. Обязательно
приватные, не публичные.

Шаг 4. В каждой папке сделай .gitignore, который исключает секреты
(пароли, ключи API, файлы .env) и временные/служебные файлы, которые
не нужно хранить в истории. Объясни, что именно ты туда добавил и почему.

Шаг 5. Сделай первый коммит и первый push в оба репозитория.

Шаг 6. Настрой автоматизацию, чтобы изменения в обеих папках сами
коммитились и отправлялись на GitHub без моего участия, но не чаще
одного раза в час. Выбери способ сам — какой посчитаешь надёжнее для
моей системы — и объясни мне простыми словами, как именно это работает
и в какой момент срабатывает.

Шаг 7. В конце покажи мне: оба репозитория созданы и приватные,
первый коммит есть, автоматизация настроена и работает.
```

## Промпт 3. Проверка системы (отчёт-светофор)

```
Проверь мою систему: бэкапы отправляются? память не разрослась?
правила не противоречат друг другу? Выдай отчёт-светофор по каждому
пункту и предложи, что стоит починить.
```
