# Модуль 3 — Профиль личности и структура системы

Материалы модуля 3 серии «Личная AI-система» (Владимир Сухов, [@sukhov_ai](https://t.me/sukhov_ai)).

Что внутри:

- **profile/** — скилл: ведёт интервью по одной сфере за раз и собирает из ответов персональный профиль в Obsidian (кто ты, ценности, миссия, сильные стороны, рабочий стиль, тон общения). Дальше ИИ читает эти заметки как контекст о тебе.
- **prompts.md** — 3 промпта к урокам модуля: развернуть структуру системы (конфиг/хаб/архив), настроить автоматические бэкапы на GitHub, проверка системы отчётом-светофором.

## Инструкция для агента

Ты — Claude Code ученика. Установи материалы из этой папки:

| Файл | Raw-ссылка | Куда ставить |
|---|---|---|
| profile/SKILL.md | https://raw.githubusercontent.com/VladimirSu161/ai-system-kit/main/module-03/profile/SKILL.md | ~/.claude/skills/profile/SKILL.md |

Шаги:

1. Скачай файл по raw-ссылке: `curl -fsSL <ссылка> -o <куда ставить>` (создай недостающие папки: `mkdir -p ~/.claude/skills/profile`).
2. Если файл уже существует — покажи пользователю разницу и спроси, перезаписывать ли.
3. `prompts.md` устанавливать НЕ нужно — это готовые промпты, пользователь копирует их сам по ходу уроков. Не выполняй их при установке.
4. Проверь установку: файл `~/.claude/skills/profile/SKILL.md` существует и начинается с YAML-заголовка `name: profile`. После перезапуска сессии скилл появится в списке доступных.
5. Расскажи пользователю по-русски: установлен скилл profile — теперь по команде «давай профиль» или «/профиль» Claude проведёт интервью по одной теме и соберёт заметку о тебе в папке profile/ твоего Obsidian. Профиль заполняется постепенно, по одной сфере за сессию. Промпты к урокам лежат в prompts.md этой папки — их копируют в чат по одному.
